What it is

Shorts Trend Desk is a private, internal analytics tool run by an independent Shorts creator. It helps plan new Shorts by showing which Shorts channels and videos are growing quickly in different countries and categories.

What it does

  • Searches for recent public Shorts by region and keyword (YouTube Data API search.list).
  • Refreshes public statistics of channels it has found — view counts, subscriber counts, upload lists (videos.list, channels.list, playlistItems.list).
  • Reads public comments on a small number of reference videos to understand audience reactions (commentThreads.list).
  • Shows the results on a dashboard that only the operator can access.

What it does not do

  • It is not distributed, sold, or offered to other users.
  • It does not sign in to YouTube accounts, upload videos, post comments, or change any YouTube content.
  • It does not collect personal information from visitors of this site.
This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
