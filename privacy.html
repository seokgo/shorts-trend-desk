Privacy Policy

Last updated: October 18, 2026

1. Use of YouTube API Services

Shorts Trend Desk uses YouTube API Services. By using this tool, you are also bound by the YouTube Terms of Service. YouTube data is handled under the Google Privacy Policy.

2. Who uses the tool

The tool is used only by its operator. It has no user accounts, no sign-up, and no sign-in with Google or YouTube. It does not request access to anyone's YouTube account (no OAuth).

3. What data the tool handles

The tool only reads public information through the YouTube Data API: channel and video identifiers, titles, publish dates, durations, view/like/comment counts, subscriber counts, and public comment text on a small number of reference videos.

It does not collect any personal information from visitors of this website. This website uses no cookies, analytics, or tracking.

4. How the data is used

The data is used only to measure which Shorts channels and videos are growing, for the operator's own content planning. It is not sold, shared, or disclosed to third parties.

5. Storage and deletion

Data is stored in a local database on the operator's computer, not on a public server. Daily statistics snapshots are deleted automatically after 7 days. Channel and video records are refreshed regularly while they are being tracked.

If you are a channel owner and want data about your channel removed, open a request at GitHub Issues with your channel URL, and it will be deleted within 7 days. You can also manage Google's access to your data at Google security settings.

6. Changes

Changes to this policy will be posted on this page with a new "Last updated" date.
